STT engines — what do you actually want here?

Right now the dropdown lists faster-whisper / WhisperX / insanely-fast-whisper, but the backend only implements openai-whisper + the YouTube-captions path. To make them real options, each one is a separate backend integration (new pip dep, a core/stt/<name>.py provider, its own model handling). That's a feature in its own right — bigger than the Settings redesign. So I want to nail down what you mean before I bake it into the design.

have it now		 The reference impl. Accurate, slow-ish. Models: tiny→large-v3, turbo. model · device (cpu/gpu) · language · VAD · fp16 already done

insanely-fast-whisper HF Transformers + batching + (on NVIDIA) flash-attention. Fastest on a good GPU; mediocre on CPU/Mac. model · batch size · device · flash-attn on/off · chunk length medium — transformers/accelerate deps; flash-attn is NVIDIA-only (won't help your Mac)

On a Mac (Apple Silicon, no NVIDIA): faster-whisper is the clear win — big speedup, runs fine on CPU. insanely-fast-whisper's headline trick (flash-attn) is NVIDIA-only, so it's not a Mac upgrade. WhisperX is worth it if you care about word-perfect subtitle timing / speaker labels.
