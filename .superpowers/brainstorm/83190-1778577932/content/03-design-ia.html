The six tabs

GeneralOutput folder · Download folder · Whisper cache folder · Logs verbosity. (All three folder fields get a "Browse…" button — see part 3.)
YouTubeCookie source (browser + profile, or a cookies.txt path) with the Test button & honest result copy · JS runtime for yt-dlp (shows the auto-detected one; warns if none). Everything about pulling video from YouTube lives here.
TranscriptionSource mode (Auto / Whisper only / YT captions only) · Whisper model + download · Device · Source language · VAD · FFmpeg 16 kHz resample.
TranslationEnable-by-default · Auto-translate title · Target language · Provider segmented control (Gemini · Local AI · OpenAI-compat) → that provider's base URL / key / model, with Test. Key is shown as •••• (saved) + "Replace" — never round-trips the mask, so Test keeps working after you save.
Subtitlesmpv executable path · font · size · text / outline / background colors (real pickers) · outline width · bold · bottom margin — with a live preview frame (see part 3).
AdvancedBackend URL (locked by default — "Edit" → validate by pinging it → apply; one-click "Reset to 127.0.0.1:8000") · Open config folder · Export / Import settings · Reset all to defaults (danger zone, real backend reset).

Search

A box at the top of the pane. Type "cookie", "gemini key", "outline", "where do files go" → live results listed as Tab › Setting; click jumps to that tab and highlights the field. Clear it → back to the current tab. Each setting carries a few keyword aliases so fuzzy terms land.
